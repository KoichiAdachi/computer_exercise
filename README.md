# 第9回 コンピュータ実習：Git演習リポジトリ

このリポジトリは、慶應義塾大学理工学部情報工学科「コンピュータ実習」第9回の演習課題用リポジトリです。
本演習では、Gitを用いたブランチ開発と履歴の統合（マージ）の基本ワークフローを学習します。

## 演習の概要
1. このリポジトリを自分の環境にクローンする (`git clone`)
2. 自分の学籍番号を含んだ開発用ブランチを作成する (`git branch`)
3. `profile.txt` を編集し、変更を記録する (`git add`, `git commit`)
4. 本番用ブランチ（`main`）に成果を統合する (`git merge --no-ff`)
5. ログを出力して提出する (`git log`)

詳しい手順は、講義スライドおよびLMS（K-LMS）の指示に従ってください。

## 注意事項
- 本番用ブランチである `main` ブランチを直接編集してコミットすることは禁止します。必ず各自でブランチを作成してから作業を行ってください。
- マージの際は、必ず `--no-ff` オプションを付与してください。
